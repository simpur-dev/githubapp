# R12 重构总方案：官方体验对齐 + API 26 原生 + 120fps + 秒开加载

> 前置调研依据（可追溯）：
> - 本地 SDK d.ts 全量核对（component/common.d.ts `ExpectedFrameRateRange` @11、@ohos.graphics.displaySync @11、navigation/tabs/web @24-26、@kit.UIDesignKit HDS 组件）
> - 官方 GitHub App 信息架构核对（2025-2026 版本为 4 Tab：Home / Notifications / Explore / Profile，来源：GitHub Docs、GitHub Blog 2026-03-20 changelog、社区讨论 #192227）
> - R9-R11 存量：三层模块架构、MVVM+V2 状态管理、Repeat virtualScroll、官方主题框架（ThemeControl.setDefaultTheme）、HdsTabs 浮动页签、非全屏窗口模型

## 0. 与目标规格的两处显式偏差（有据可查）

1. **Tab 数量**：目标规格列 5 Tab（首页/探索/代码/通知/个人资料）；官方 App 实际为 4 Tab（无"代码"Tab，搜索在首页顶部）。
   **决策：按目标规格实现 5 Tab**，"代码"Tab 承载全局搜索（含仓库/用户/代码搜索分类），即官方 App 搜索能力的一级入口化。既有 bootTab 契约（dynamic/trend/my）全部保持兼容。
2. **GraphQL**：REST 为主、GraphQL 客户端预留（见 05 技术选型）。核心列表接口今晚不切 GraphQL —— 收益（少一次聚合请求）小于风险（限流/字段映射回归面大），决策依据见选型文档。

## 1. UX 信息架构（P1）

```
HomePage（HdsTabs 浮动页签，5 Tab）
├─ 首页 Feed      DynamicTabPage   （received_events 动态流）   icon=house
├─ 探索 Explore   TrendTabPage     （趋势仓库）                icon=compass
├─ 代码 Code      SearchPage 嵌入  （全局搜索：仓库/用户）       icon=code
├─ 通知 Notif.    NotificationsTabPage（新，复用 NotifyContent）  icon=bell
└─ 个人资料       MyTabPage        （个人主页）                 icon=person
```

- 旧 3 Tab（动态/趋势/我的）key 不变（dynamic/trend/my），bootTab 参数与 scenario-tour 契约兼容；
  新增 code / notifications 两个 bootTab 取值。
- 抽屉保留（侧滑呼出 = 目标的"侧滑快捷入口"）；首页右上搜索按钮保留（官方也是首页顶搜索）。
- 通知页 push 路由保留（bootNotifyIssue 深链/既有测试不变），Tab 与 push 页共用 NotifyContent 组件与各自 ViewModel 实例。

## 2. 性能方案（P2/P4，详见 03 专项文档）

- **帧率**：ArkUI 系统按需调度（滚动/动画在 120Hz 设备自动满帧）；显式动画用 `expectedFrameRateRange {min:90,max:120,expected:120}` 声明；
  自绘连续动画才需要 displaySync。禁止定时器逐帧动画（现存代码已合规，本轮复查）。
- **列表**：Repeat virtualScroll（V2 版 LazyForEach 等价物，R10 已全量）+ cachedCount 分级校准（图片多的列表 8，纯文本 5）；
  行组件 @Reusable 评估（V2 @Reusable 支持情况见 05 选型）。
- **骨架屏**：通知 Tab / 仓库详情 / 动态流首屏 loading 升级为骨架占位（现有 spinner 保留为次选）。
- **秒开**：缓存优先策略已有（RDB 事件缓存/README 缓存），补齐：Tab 首次激活即预拉下一 Tab 头屏数据（预请求）。

## 3. 动效体系（P4）

- 页面转场：Navigation 默认系统转场（已符合官方横滑手感）+ 手势返回原生管线，不加自绘转场。
- 按压反馈：PressableCard（R10，属性动画 120ms）全列表覆盖。
- 列表动效：Refresh 原生下拉（已有）；分段切换 150ms 属性动画（已有）。
- 新增：Tab 首次切入内容 fade-in（120ms 属性动画），数字/状态变化走 @Trace 驱动的属性动画。

## 4. 问题闭环（见 02 问题排查报告）

R11 已闭环 A1-A10/B1-B2/B4；R12 处理目标中点名的：通知左滑（P3，HdsListItem）、批量已读（通知 Tab 头部按钮 + push 页菜单双入口）、骨架屏、通知 Tab 化直达。
