## 5. 脚本/环境坑（非应用 Bug，沉淀备查）

| 现象 | 原因 |
|---|---|
| `aa start --ps bootXxx 'a|b'` 参数含竖线时注入失效 | 竖线被 hdc shell 解释为管道；整条命令与参数都要引号包裹（`"--ps" "bootXxx" "a|b"`） |
| tap 后立即截图内容未切换 | HdsTabs 首次构建目标 Tab 需要时间，验证脚本 wait 需 ≥3s（非应用 Bug） |
| dumpLayout JSON 中 bounds 键排序在 id 之前 | 坐标提取须从 id 位置向前（负方向）搜索最近的 bounds |

## 6. 复判为"非缺陷/设计取向"（不再动）

- 首页 AppBar 与用户头部浅色模式下保持深色：GitHub 品牌设计（官方客户端同为深色头部），代码全走 token。
- 通用列表页"标题重复"：页内标题是分区头，测试 id 契约要求保留。
- 通知 403：token 权限配置问题（见 F1）。
