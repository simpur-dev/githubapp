# R12 120 帧满帧性能优化专项方案

> 依据：本地 SDK d.ts 核对（`ExpectedFrameRateRange` @11 common.d.ts、`@ohos.graphics.displaySync` @11）、
> ArkUI 声明式渲染管线（V2 状态管理细粒度更新）、HarmonyOS 高刷调度机制。

## 1. 帧率机制与本项目的适配结论

ArkUI 应用**不需要**也不能"全局开启 120Hz"：系统渲染管线按场景自动调度——滚动/手势/动画期间
请求高刷，静态画面自动降帧省电。应用侧的工作是**把动画声明进高刷调度**：

1. **显式动画帧率声明**（本轮已落）：
   - `animation({ expectedFrameRateRange: { min: 60, max: 120, expected: 120 } })`
   - 已声明点位：SkeletonList 呼吸循环动画（iterations:-1 唯一的持续动画）、PressableCard
     按压反馈（缩放+蒙层透明度）、通知分段切换条（150ms）。
   - 声明原则：只对**交互期动画**声明满帧；转场动画走系统默认（系统已按手势满帧调度）。
2. **自绘连续动画**（displaySync @11）：本项目无秒表/仪表类常驻自绘动画，未使用；若未来引入，
   必须经 `displaySync` 订阅 vsync，禁止 setInterval/setTimeout 逐帧驱动。
3. **禁止项（目标规格红线）**：JS 逐帧动画、定时器动画、自定义帧循环——已全量 grep 复查，存量 0。

## 2. 渲染全链路优化（已落地清单）

| 项 | 落地方式 | 证据 |
|---|---|---|
| 布局扁平化 | 列表行统一"Row→PressableCard(Stack)→Column"三层内结构；R12 移除蒙层常驻节点后行内无冗余层级 | PressableCard.ets |
| 细粒度状态 | 全量 V2：@ObservedV2/@Trace 驱动，列表数据整体替换仅在数据变化时触发行更新；调色板 @Trace 单例订阅 | ThemeManager/各 ViewModel |
| 减少透明混合 | 浮动页签遮罩为渐变遮罩（系统合成），无大面积 backdrop blur；弹窗系统材质由系统合成器处理 | HomePage barFloatingStyle |
| 像素对齐 | 全部间距/圆角为 token 整数值（vp），无 .5vp 圆角、无亚像素偏移 | Theme.ets |
| 组件复用 | Repeat virtualScroll（V2 版 LazyForEach 等价）+ memoryOptimizationStrategy（API 26 自动缓存优化） | PullLoadMoreList.ets |
| 线程分离 | 网络全部 async（HttpManager）、DB RDB 异步、无主线程 IO；MD4C markdown 解析在 C++ 侧 | common/base/net、feature-repo/cpp |

## 3. 秒开加载体系（与 04 文档联动）

- 冷启动：`ThemeManager.init()` 前置于 `loadContent`（onCreate 链），首页骨架即骨架屏结构；
  boot 深链 600ms 内完成 push（schedule* 表驱动）。
- 热启动：`EVENT_BOOT_REDELIVERED` 重投消费（R11 B1），实测深链 3s 内直出目标页数据。
- 二级页：缓存优先（RDB 事件缓存/README 缓存 onCached 回调先出缓存再刷新）。

## 4. 实测与验收方法

| 指标 | 方法 | 结果记录 |
|---|---|---|
| 滚动稳定性 | 趋势页 8 连快滑（uitest swipe 120ms/次）后截图 + pid 存活 | 无白块、无崩溃（r12_fastscroll.jpeg） |
| 启动时长 | 冷启动 aa start → 首页骨架可见 ≈6-9s（模拟器含系统欢迎页停留；真机上欢迎页跳过逻辑不同，需真机复测） | 登记待真机项 |
| 热启动深链 | 应用存活时 aa start 带参 → 3s 内目标页数据直出 | r12_skeleton2.jpeg |
| 帧率采集 | SP_da / `hidumper -s RenderService`（模拟器刷新率与真机不同，帧率数据以真机为准） | 登记待真机项 |

> 说明：模拟器（Mate 80 Pro 镜像）刷新率与高端真机 120Hz 面板不同，**满帧结论必须在真机上用
> SP_da 采集后闭环**；模拟器上能闭环的是：无白块、无崩溃、动画管线正确（无 JS 逐帧）、
> 状态更新粒度（dumpLayout 中可见节点数符合预期）。
