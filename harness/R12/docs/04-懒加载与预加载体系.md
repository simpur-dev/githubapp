# R12 懒加载与预加载体系设计

## 1. 长列表懒加载（全部列表场景）

- **实现**：V2 范式下统一走 `Repeat virtualScroll`（V2 版 LazyForEach 等价物，R10 已全量迁移），
  叠加 API 26 `memoryOptimizationStrategy: ENABLE_AUTO_CACHE_OPTIMIZATION` 自动缓存优化。
- **统一容器**：所有分页列表经 `PullLoadMoreList`（common/ui/components）——Refresh 下拉 + List
  virtualScroll + 页脚态（加载中/没有更多）+ 空态/错误态（EmptyState）+ 可选左滑（enableRowSwipe）。
- **key 规则**：index + 内容摘要（前 96 字符），保证整页替换后行重建、局部刷新行复用。

## 2. 预缓存分级（R12 P2 落地）

| 列表 | cachedCountParam | 依据 |
|---|---|---|
| 动态流（EventItem，头像+多行文本） | 8 | 行高 ~130vp，快滑时缓冲需覆盖惯性距离 |
| 我的-动态（EventItem） | 8 | 同上 |
| 探索/趋势（RepositoryItem，头像+星标行） | 8 | 同上 |
| SubListView（仓库/用户列表，RepositoryItem/UserItem） | 8 | 同上 |
| 通知（NotifyContent 行，纯文本卡片） | 默认 5 | 文本行渲染轻，5 足够 |
| 文件列表/Issue 列表（FilesTab/IssueTab） | 默认 5 | 同上 |

## 3. 内容分段懒加载

- 仓库详情页：`Tabs` 四页签（详情/Readme/Issue/文件），TabContent 懒构建——未切到的页签不构建
  不请求；详情页 VM 串行预取（info → star 状态 → README → 活动 → Issue → 文件）中 README/文件
  均有 RDB 缓存先出（onCached 回调）。
- 长内容折叠：CodeDetail 超长文件走"预览 + Web 展开"分支；markdown 渲染上限行数约束。

## 4. 数据预请求与缓存优先

| 场景 | 策略 |
|---|---|
| 仓库事件 | RDB 缓存（readEventCache → onCached 先渲染）+ 网络刷新替换 |
| README | readmeHtml 缓存回调先出，markdown 就绪后切换 |
| 列表上拉 | onReachEnd 触发 loadMore（分页预取下一页，页脚无感衔接） |
| 深链热启动 | onNewWant → EVENT_BOOT_REDELIVERED → HomePage 重投消费 BootChannel（R11 B1） |
| 图片 | Image 组件系统缓存 + alt 占位（R10 已补）；离屏行由 virtualScroll 回收，解码随行生命周期 |

## 5. 页面/组件预加载

- Tab 页签：HdsTabs TabContent 懒构建（首次切入才实例化），切过即驻留——Tab 间往返零重建。
- 高频路由：Navigation 栈内 NavDestination 常驻（stackSizeLimit 30，R10），返回即恢复不重载。
- 复杂组件：MarkdownRenderer（C++ MD4C）常驻实例由宿主页持有，Tab 内切换不销毁。

## 6. 骨架屏（感知优化）

- `SkeletonList`（common/ui/components）：圆头像块+文字块骨架，呼吸动画（0.55↔1 alpha，
  900ms EaseInOut Alternate 循环，expectedFrameRateRange 60-120）。
- 接入点：通知首屏（NotifyContent.buildInitialLoading）；推广点：动态/趋势首屏（登记待办）。
