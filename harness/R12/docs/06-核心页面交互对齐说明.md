# R12 核心页面交互对齐说明（对照 GitHub 官方 App）

> 对齐基准：GitHub Mobile 2025-2026（Home / Notifications / Explore / Profile 四 Tab + 首页顶部搜索）。
> 本项目按目标规格实现五 Tab（详见 05 文档 §2.3）。动效参数均为代码中的实际值。

## 1. 信息架构对齐表

| Tab | 本项目 | 官方对应 | 图标（系统符号） | 对齐点 |
|---|---|---|---|---|
| 首页 | DynamicTabPage（received_events 流） | Home | house | 动态卡片（头像+行为+对象+时间）、下拉刷新、点击跳转 |
| 探索 | TrendTabPage（趋势仓库） | Explore | compass | 趋势卡片（仓库名/语言/描述/星标/Fork） |
| 代码 | SearchPage 嵌入 | （官方为首页顶搜索，此处入口化） | code | 搜索框+历史+分类（仓库/用户） |
| 通知 | NotificationsTabPage | Notifications/Inbox | bell | 未读圆点、三段过滤（未读/参与/所有）、左滑已读、批量已读 |
| 个人资料 | MyTabPage | Profile | person | 头部（头像/计数/加入时间）、动态区、设置入口 |

## 2. 全局交互

| 交互 | 实现 | 动效参数 |
|---|---|---|
| 侧滑呼出侧边栏 | SideBarContainer Overlay（系统手势+遮罩） | 系统默认 |
| 左滑返回 | Navigation 系统转场+手势 | 系统默认（手势跟手） |
| 浮动页签 | HdsTabs barFloatingStyle（材质/遮罩/底距 token 化） | 系统材质合成 |
| 按压反馈 | PressableCard（overlay 蒙层 + 0.98 缩放） | 120ms EaseOut |
| 深浅色 | 官方主题框架 + setColorMode；调色板 @Trace 响应 | 即时（无过渡动画，避免闪屏） |
| 状态栏 | 页面级声明背景色/图标深浅，退后台重置 | 即时 |

## 3. 分页面对齐细节

### 首页 Feed
- 卡片：头像 40vp + 用户名（small）+ 行为描述（middleWhite 次色）+ 相对时间；按压整卡反馈。
- 列表：Refresh 原生下拉 + onReachEnd 上拉；预缓存 8。
- 长按快捷菜单：未实现（登记，见 02 报告 F2）。

### 仓库详情
- 头部：全名/语言/大小/License/描述/创建更新时间/星标-Fork-关注-Issue 计数行（id 契约保留）。
- 页签：详情/Readme/Issue/文件，TabContent 懒构建；Readme 原生 MD4C 渲染 + 链接跳转（accent 色）。
- 底部操作条：Star/Watcher/Fork + 分支选择（浮动条，避让手势区）。

### Issue/PR
- 列表：状态 pill（open 绿/closed 红 token）+ 筛选；详情：楼层评论 + 底部回复条 + markdown 工具栏。

### 搜索（代码 Tab）
- 历史记录（bootSearchHistory 种子验证过）+ 分类芯片（仓库/用户）+ 结果分页。

### 通知
- 未读 accent 圆点 + 三段过滤条（150ms EaseInOut 切换）+ 左滑"标记已读"（accent 底 96vp 露出区）+
  批量已读双入口（Tab 头部勾按钮 / 推送页标题栏 done_all 菜单）。

### 个人主页
- 头部：头像/名称/副名/铃铛（未读数）/计数四格/加入时间；头像点按 = 设置入口；计数点按 = 通用列表。

## 4. 状态页面规范

| 态 | 组件 | 视觉 |
|---|---|---|
| 首屏加载 | SkeletonList（通知）/LoadingProgress（其余页） | 呼吸骨架 900ms / 主色转圈 |
| 空态 | EmptyState（SymbolGlyph + 标题，i18n） | textSecondary 图标+text 标题 |
| 错误态 | EmptyState + 重试胶囊按钮 | accent 底 + onBrandText 字（"重试"） |
| 网络离线 | CommonToast 提示 + NetworkMonitor 恢复提示 | 系统深浅自适应 |

## 5. 与官方尚存的差距（登记，非本轮范围）

1. Feed 卡片快捷操作（点赞/评论按钮内联）——官方 Feed 为用户行为流，无内联操作按钮，等价满足。
2. 列表行长按菜单（F2）。
3. 共享元素转场（头像/仓库头图）——Navigation sharedTransition API 已具备，需逐页标注 geometry id，登记 R13。
4. 系统级通知推送——需服务端/推送服务配合（05 文档 §3）。
